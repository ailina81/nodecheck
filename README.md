# 🧱 NodeCheck — прототип

**ИИ-аудит совместимости отделочных материалов и соответствия строительным нормам.**

## Проблема
При проектировании интерьеров архитекторы и дизайнеры допускают скрытые технические ошибки в спецификациях
отделочных материалов: несовместимость покрытий с тёплым полом, нарушения влагостойкости и пожарной безопасности.
Ручная проверка — человеческий фактор, дорогие переделки на стройке и замечания экспертизы.
NodeCheck автоматизирует физико-технический и нормативный аудит материалов.

**Целевая аудитория:** архитекторы, дизайнеры интерьеров, студенты-архитекторы.

## Что делает
1. **Анализирует совместимость материалов** — тёплый пол, влагостойкость, клеевые составы, основания.
2. **Сверяет с нормами** — пожарная безопасность отделки путей эвакуации (классы КМ0–КМ5), мокрые зоны, детские.
3. **Предлагает альтернативы** — в выбранном бюджете (эконом / средний / премиум) и стиле, с объяснением.
4. **Подбирает более дешёвые аналоги** без потери технических свойств.
5. **Формирует PDF-отчёт** для скачивания.

## Как устроено
```
Пользователь ─► Streamlit-интерфейс (app.py)
                    │
                    ├─► База правил (engine.py) — ~25 материалов, свойства: влагостойкость,
                    │   макс. t тёплого пола, класс пожарной опасности КМ; правила проверки
                    │
                    └─► LLM (OpenAI / Gemini) — системный промпт «инженер-материаловед + эксперт СП РК»,
                        получает спецификацию + находки правил, проверяет/дополняет, возвращает JSON
                    ▼
            Светофор 🟢/🔴 · карточки ошибок · рекомендации · дешёвые аналоги · PDF-отчёт
```
**Гибридный подход:** база правил даёт стабильный результат даже без интернета и ключа,
LLM дополняет анализ материалами, которых нет в базе, и формулирует объяснения.

## Структура
| Файл | Назначение |
|---|---|
| `app.py` | Интерфейс + вызов LLM |
| `engine.py` | База знаний материалов, движок правил, подбор дешёвых аналогов |
| `report.py` | PDF-отчёт |
| `fonts/` | Шрифт DejaVu для кириллицы в PDF |
| `requirements.txt` | Зависимости |
| `.env.example` | Шаблон настроек API-ключа |

## 🚀 Инструкция по запуску

### 1. Установить Python 3.10+
Проверка: `python --version`. Скачать: https://www.python.org/downloads/
(Windows — при установке отметить **«Add Python to PATH»**).

### 2. Установить зависимости
Откройте терминал в папке проекта:
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. (Необязательно) Подключить ИИ
Без ключа приложение работает на встроенной базе правил. Чтобы включить LLM:
```bash
cp .env.example .env      # Windows: copy .env.example .env
```
и впишите ключ в `.env`:
- **OpenAI:** `LLM_API_KEY=sk-...`, `LLM_MODEL=gpt-4o-mini`
- **Gemini (есть бесплатный ключ):** получите ключ на https://aistudio.google.com/apikey, затем
  `LLM_API_KEY=AIza...`, `LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/`,
  `LLM_MODEL=gemini-3.8-flash` (актуальное имя модели смотрите в AI Studio)

Ключ также можно вставить прямо в боковой панели приложения.

### 4. Запустить
```bash
streamlit run app.py
```
Браузер откроется на http://localhost:8501

### 5. Сценарий демонстрации
1. В списке **«Загрузить пример»** выберите **«Санузел с ошибками»** → «Запустить ИИ-аудит» → 🔴 4 критичных конфликта и замены.
2. Выберите **«Санузел правильный»** → 🟢 «Всё отлично».
3. **«Коридор общежития»** → нарушения пожарных классов КМ на пути эвакуации.
4. Добавьте свою строку в таблицу (например, «Пол — пробка») и включите тёплый пол — покажите, как ИИ реагирует.

### 6. Публикация онлайн (нужно для КТ 3 — публичная ссылка)
1. Создайте **публичный** репозиторий на GitHub и загрузите туда все файлы проекта (**без `.env`!**).
2. Зайдите на https://share.streamlit.io через GitHub → **Create app** → выберите репозиторий, ветку `main`, файл `app.py`.
3. **Advanced settings → Secrets**, вставьте:
   ```toml
   LLM_API_KEY = "AIza...ваш ключ Gemini"
   LLM_BASE_URL = "https://generativelanguage.googleapis.com/v1beta/openai/"
   LLM_MODEL = "gemini-3.8-flash, gemini-flash-latest, gemini-flash-lite-latest"
   ```
4. **Deploy** → получите ссылку вида `https://nodecheck.streamlit.app`.
5. Проверьте ссылку с телефона в режиме инкогнито: должна открываться без входа. Логин и пароль не нужны.
6. В боковой панели приложения должен быть включён «Использовать LLM», а в результате — «Режим: LLM (gemini…)».

## Ограничения прототипа
- Классы пожарной опасности и свойства материалов в базе — типовые/усреднённые; реальные значения зависят от сертификата конкретного продукта.
- Ссылки на нормы (СП РК 2.02-101, EN 1264, EN 12004) даны на уровне документа — точный пункт сверяйте с актуальной редакцией.
- Результат справочный, не заменяет экспертизу проекта.

## Развитие
Загрузка спецификации из Excel/PDF · RAG по полным текстам СП РК · каталог материалов с ценами · экспорт отчёта в PDF.
